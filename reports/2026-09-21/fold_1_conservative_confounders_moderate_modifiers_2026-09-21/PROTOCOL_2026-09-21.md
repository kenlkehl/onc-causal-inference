# Fold 1: conservative confounder retention and moderate modifier pruning — 2026-09-21

1. Purpose and interpretation
   1. Test the user's requested middle ground after inspecting the preceding consolidation results.
   2. This is an exploratory, post-hoc comparison on an already examined outer fold. Freezing predictions before this run's oracle evaluation does not restore an untouched test set.
2. Frozen selection rule
   1. Restore every confounder from the original completed multi-model adjudication (189 candidates).
   2. Retain the first 16 modifiers in the accepted global review's existing ranking. Sixteen had the minimum mean inner-fold R-loss among the previously evaluated prefixes; the earlier one-standard-error simplification selected eight instead.
   3. Do not rerank, manually add oracle features, re-extract measurements, or request new LLM decisions.
   4. Preserve original candidate order and measurement definitions. Set treatment and outcome nuisance support for every retained confounder. The native estimator also includes modifiers in outcome nuisance models.
3. Estimation
   1. Fit three forests with the 16 modifiers using the exact saved all-candidate nuisance residuals and fixed 720/180 overlap cohort. Seeds: 120042, 1120042, 2120042. Compare with frozen eight- and 224-modifier forests on the identical 180 held-out patients.
   2. Fit the native production estimator for seeds 100042, 1100042, 2100042 with the restored confounders and 16 modifiers. Modifiers enter X; confounders without modifier roles enter W; dual-role features appear once in X and also contribute to internal nuisance fitting.
   3. Preserve historical settings: 200 trees, minimum leaf size 10, square-root feature subsampling, sample fraction 0.45, honesty and inference enabled, no forest tuning; elastic-net logistic nuisance models and original five inner splits; propensity bounds 0.1–0.9 and clipping at 0.02.
   4. Compare production predictions with the preceding eight-confounder/eight-modifier estimator. Report both native eligible populations and their common held-out patients because eligibility can change.
4. Evaluation and limitations
   1. Freeze selection, source hashes, and all six new prediction sets before computing new oracle metrics.
   2. Report ITE correlation, RMSE, bias, effect dispersion, interval coverage, and production AIPW ATE with its estimated interval and target-population oracle ATE.
   3. Audit direct oracle recovery separately from proxies, using the existing lineage mapping only during evaluation.
   4. Three seeds describe algorithmic variability on the same fold, not independent statistical replications. Candidate retention does not guarantee nonzero nuisance coefficients or accurate extraction. Prior fold-1 results influenced the decision to run this variant.
   5. Check hashes, row alignment, role routing, cohort consistency, actual fitted nuisance clones, and optimization diagnostics. Keep all earlier experiment files unchanged.
