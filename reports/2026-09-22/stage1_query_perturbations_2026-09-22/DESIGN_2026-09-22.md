# Stage 1 query perturbations for feature discovery — September 22, 2026

1. **Question and proposed first experiment**
   1. Can small edits to a learned semantic query identify which clinical
      concepts account for its treatment, outcome, or heterogeneity signal?
   2. Start with an effect-query perturbation diagnostic in outer fold 1. Compare
      each original query with an edited query whose training effect moment is
      reduced, plus random edits of the same size. Measure all three signals.
   3. The output of interest is a contrast between retrieved clinical evidence
      before and after editing, followed by additional executable feature
      candidates. A query with a small score is not itself a useful new feature.
   4. This file is a design and repository inspection, not experimental results.
      No perturbation fitting or feature-generation LLM calls have run yet.

3. **What the existing neural-query mechanism actually learns**
   1. Each context has three banks: five treatment queries, five outcome queries,
      and five effect queries. Saved vectors in the current cohort have 4,096
      coordinates. A query is shared across patients; the patient-specific
      quantity carrying a signal is its activation, not the query coordinates.
   2. With normalized query `q` and normalized text-chunk embeddings `z_ij`,
      patient activation is `a_i(q) = t * log(mean_j exp(q dot z_ij / t))`.
      The configured temperature `t` is 0.05. This is a smooth approximation
      to retrieving the most similar chunks and is differentiable in `q`.
   3. Treatment and outcome queries maximize standardized direct contrasts in
      these activations. For binary targets this reflects a between-group
      difference in mean activation. It is not a fitted clinical concept label.
   4. Effect queries use `u = T - e_hat`, `v = Y - m_hat`, and the contribution
      `u * (v - tau_0 * u)`, where `tau_0` is the fitted constant residual effect.
      Their moment centers activation with weights `u^2`. This targets a
      departure from a constant effect, conditional on nuisance quality.
   5. Query fitting also encourages vector/activation diversity, limits drift
      from its initialization, and discourages vanishing activation variance.
      All final queries are retained; validation scores do not gate them.
   6. Evidence generation currently sorts patients by their best chunk cosine,
      while model training uses log-mean-exp activation across chunks. A
      perturbation analysis should report both retrieval and activation changes;
      the two orderings need not coincide.
   7. Relevant implementation: `oci/inference/neural_cohort_witness.py`
      (`cohort_contribution`, `fit_soft_contrast_queries`, `_torch_soft_activations`),
      `neural_query_discovery_runtime.py` (`_fit_subfold`, `_fit_final_bank`), and
      `neural_query_agentic_forest.py` (`build_query_evidence`).

4. **Edits worth comparing**
   1. **Suppress a selected signal.** Search near each unit query for a new unit
      query that reduces the squared treatment, outcome, or effect moment.
      Penalize drift and preserve nontrivial activation variance. Report the
      entire signal-versus-distance curve instead of choosing a threshold after
      seeing validation outcomes. Standardize against fixed training scales so
      the optimizer cannot win merely by inflating a score denominator.
   2. **Preserve other behavior where feasible.** Record what happens to the two
      other signals and semantic retrieval. An optional constrained arm can
      preserve them, but failure to satisfy both conditions is informative.
      A real modifier can also predict treatment or outcome; nuisance independence
      is not a requirement for being an effect modifier.
   3. **Equal-size random controls.** Apply random rotations with exactly the
      edited query's unit-vector distance, using prespecified seeds. A learned
      edit should do more than ordinary retrieval instability would explain.
   4. **Semantic edits.** Once a clinical theme is proposed from literal excerpts,
      use paired descriptions or a learned concept direction to test it. Treat
      vector subtraction as a hypothesis about the encoder, then verify it on
      patient activations and real text. A coordinate or direction has no
      automatic clinical interpretation.
   5. **Text deletion and rescue.** Mask the implicated concept's spans, re-embed
      those texts in a separate cache, and test whether signal loss recurs and
      reverses on restoring the original spans. Compare size-matched irrelevant
      spans. This tests model reliance, not the causal effect of the clinical
      variable in patients. Synonyms and correlated proxies may preserve signal.

5. **What would count as removing signal**
   1. Separate three claims: the original moment shrinks; a frozen downstream
      predictor loses accuracy; independently refitted predictors cannot recover
      useful information. They are different tests.
   2. A zero mean contrast does not rule out nonlinear signal. Opposing subgroups
      can cancel, and joint information with other queries can remain. Test
      regularized linear probes and a limited nonlinear probe, both alone and
      conditional on the remaining query bank.
   3. Evaluate treatment/outcome probes with held-out log loss (or squared loss
      for a continuous outcome). Report losses relative to a constant prediction
      and relative to the remaining bank without this query.
   4. Evaluate effect probes with held-out R-loss:
      `mean((v - u * tau_hat(activations))**2)`, using identical nuisance residuals
      and eligible patients across all edits. Include a fitted constant-effect
      baseline. Avoid dividing by treatment residuals to create noisy ITE labels.
   5. A frozen predictor failing while a refitted predictor succeeds suggests
      the edit changed the encoding rather than removed usable information.
      Even both failing supports only the tested probe classes and sample size.
   6. Query-vector orthogonality does not imply independent patient activations.
      Do not use an orthogonal vector projection as the only erasure diagnostic.

6. **Turning a perturbation into better discovery**
   1. Save matched before/after evidence for the same patients: changes in chunk
      similarities, smooth retrieval weights, activations, and cohort-moment
      contributions. Include retained evidence and matched random-edit controls.
   2. Give the LLM literal excerpts with provenance and ask which measurable
      clinical distinctions explain what disappeared. Require a baseline-time
      definition and extraction contract; do not supply oracle variables or
      accept claims that the perturbation establishes a causal role.
   3. A second discovery arm should search for **remaining** useful signal after
      already measured candidates are accounted for. Use training-cross-fitted
      treatment/outcome prediction residuals and an effect residual contribution
      `u * (v - u * tau_baseline)`, with `tau_baseline` itself cross-fitted.
      This is a new residual-discovery objective, not the current constant-effect
      objective. Keep baseline predictions fixed across search candidates.
   4. Prevent repeated proxy discovery by checking incremental predictive value
      conditional on existing measurements and examining semantic overlap.
      Compare with a simpler increase in query count or independent initializations.
   5. Preserve the original broad discovery output. Add perturbation-derived
      evidence with its own provenance; do not prune candidates because an edit
      or a small-sample validation score failed.

7. **Bounded fold-1 pilot**
   1. Reuse the five saved `outer_001_inner_00*` contexts: each has 640 training
      and 160 validation patients, with five queries per bank. Keep the outer
      200 patients aside. Do not split the full-800 fitted queries after the
      fact and call their resulting validation scores independent.
   2. Check frozen embedding, row/text, configuration, and query bindings;
      reproduce stored activations before optimization. The inventory establishes
      availability and split compatibility, not full historical provenance.
   3. Freeze query-edit distance budgets of 0.02, 0.05, 0.10, and 0.20 measured
      as Euclidean distance between unit vectors. Use several deterministic
      training-only restarts; near an optimized query, a gradient alone may be
      small even when finite edits matter. Do not select restarts on validation.
   4. Start with the 25 effect queries across these contexts. Use effect-score
      suppression and matched random edits; measure treatment and outcome signal
      as secondary diagnostics. Subsequently repeat with nuisance-targeted edits.
   5. Recover correctly scoped Stage 1 nuisance predictions if available;
      otherwise refit them within each 640-patient training context, with strict
      cross-fitting for training residuals and external predictions for its 160
      validation patients. The original query NPZ files do not contain nuisances.
      Do not substitute nuisance fits that trained on those validation patients.
   6. Use the 640 patients for edit fitting, probe fitting, and evidence/LLM
      construction. Freeze edits, probes, and proposed definitions before using
      the 160 validation outcomes. Tune any edit/probe hyperparameters only in
      further training splits, or treat the prespecified grid descriptively.
   7. Judge success by reproducible held-out signal attenuation beyond random
      controls, interpretable lost concepts, and novel useful extracted features.
      Oracle recall is an after-the-fact synthetic-cohort diagnostic. A later
      downstream experiment must evaluate CATE performance and equal-budget
      discovery alternatives; attenuation alone does not demonstrate improvement.
   8. Report per-fold results and query/seed variation without treating repeated
      queries, overlapping training folds, or random edits as independent cohorts.
      This previously examined cohort supports exploratory comparisons.

8. **Related methods and their limits here**
   1. [TCAV](https://proceedings.mlr.press/v80/kim18d.html) uses concept directions
      and directional sensitivity. It motivates interpretable edit directions,
      but concept examples must first be identified and validated.
   2. [LEACE](https://arxiv.org/abs/2306.03819) gives minimal-distortion linear
      concept erasure. Its linear-predictor guarantee does not automatically
      transfer to our nonlinear chunk pooling, forests, or unseen patients.
   3. [R-learning](https://arxiv.org/abs/1712.04912) motivates the residual loss
      for measuring remaining effect-prediction value under fixed nuisances.
   4. [Attention is not Explanation](https://aclanthology.org/N19-1357/) shows
      why attention changes alone should not be treated as a faithful explanation.
      Our proposed perturbation and probe checks address that concern empirically;
      they do not make a claim of causal identification.
